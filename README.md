# Календарь спортивных событий 2026–2027

Статический лендинг: календарь спортивных и киберспортивных событий с 21.09.2026 по 31.12.2027 — карта года, календарь по дням, фильтры по видам спорта и играм, карточки турниров, топ самых популярных событий.

## Запуск

Сборка не нужна — это чистые HTML/CSS/JS. Достаточно отдать папку любым веб-сервером (nginx, Apache, GitHub Pages, Netlify и т. п.), корень — `index.html`.

Локально:

```bash
python -m http.server 8765
```

## Структура

- `index.html` — разметка страницы
- `css/style.css` — стили
- `js/data.js` — все события, рейтинг, статусы допуска, ожидаемые анонсы (формат полей описан в начале файла)
- `js/app.js` — логика календаря и фильтров

## Версия для вставки на чужой сайт

`exports/calendar-embed.txt` — готовый блок `<div id="mbc">…</div>` со стилями и скриптом внутри. Его один раз вставляют в страницу сайта; события он подгружает из этого репозитория (`data/events.json`), поэтому после обновления данных сайт обновляется сам.

После любой правки `js/data.js` нужно пересобрать данные и блок:

```bash
python tools/build_embed.py
```

Скрипт обновляет `data/events.json` и `exports/calendar-embed.txt`. Дальше обычный коммит и пуш — сайт подхватит новые события при следующем открытии страницы.

Важно: для работы блока репозиторий должен быть **публичным** — иначе `raw.githubusercontent.com` не отдаст данные.

## Ссылки на турниры в линии

Клик по карточке ведёт на страницу турнира в линии. Адрес берётся из поля `url` у события в `js/data.js`:

```js
{ id:'rpl', t:'РПЛ 2026/27', …, url:'https://melbet.ru/ru/line/football/…' },
```

Если у события поля `url` нет, используется общий `LINE_URL` из `js/app.js`. Так что можно сначала проставить общую ссылку на раздел спорта, а точные адреса турниров добавлять по мере необходимости.

## Важно при каждом обновлении

В `index.html` у стилей и скриптов стоит версия: `style.css?v=2026-10-03`. **После правок в `css/` или `js/` меняйте это число во всех трёх строках** — иначе браузеры и CDN продолжат отдавать старые файлы, и правки не будут видны на сайте.

## Настройка

В начале `js/app.js`:

- `LINE_URL` — общая ссылка на линию: куда ведёт клик по карточке, если у события нет своей ссылки
- `BONUS_URL` — ссылка кнопки «Забрать бонус»
- `TODAY` — дата актуальности данных (подсвечивается в календаре)
