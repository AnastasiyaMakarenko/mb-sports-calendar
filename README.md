# Календарь спортивных событий 2026–2027

Статический лендинг: календарь спортивных и киберспортивных событий с 21.09.2026 по 31.12.2027 — карта года, календарь по дням, фильтры по видам спорта и играм, карточки турниров, топ самых популярных событий.

## Запуск

Сборка не нужна — это чистые HTML/CSS/JS. Достаточно отдать папку любым веб-сервером (nginx, Apache, GitHub Pages, Netlify и т. п.), корень — `index.html`.

Локально:

```bash
python -m http.server 8765
```

## Структура

- `index.html` — разметка страницы
- `css/style.css` — стили
- `js/data.js` — все события, рейтинг, статусы допуска, ожидаемые анонсы (формат полей описан в начале файла)
- `js/app.js` — логика календаря и фильтров

## Настройка

В начале `js/app.js`:

- `LINE_URL` — ссылка кнопок «Перейти в линию»
- `BONUS_URL` — ссылка кнопки «Забрать бонус»
- `TODAY` — дата актуальности данных (подсвечивается в календаре)
